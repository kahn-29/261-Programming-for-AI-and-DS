\paragraph{Shared machine learning responsibilities.}
Võ Nhật Tân and Phan Ngọc Lan Chi jointly establish the constant-median and local median-price-per-square-metre baselines, prepare the shared feature representation and chronological evaluation protocol, compare the machine learning models, and write the machine learning report. Each member is assigned four learned model configurations. The text-only TF-IDF Ridge model also supplies the prediction feature used by the text-enhanced LightGBM.

\paragraph{Shared deep learning responsibilities.}
Ngân Phạm and Minh Thiện are each responsible for one principal neural model. They jointly compare the deep learning results, implement and evaluate the prediction blends combining structured and text-based models, and write the deep learning report.
